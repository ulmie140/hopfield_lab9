# Экспертная система: Нейронная сеть Хопфилда

> Интеллектуальное веб-приложение для моделирования автоассоциативной памяти и распознавания зашумленных образов. Проект разработан в рамках лабораторной работы №9 по дисциплине "Базы знаний и поддержка принятия решений".

## Описание задачи
Система реализует однослойную симметричную нейронную сеть с обратными связями, способную запоминать и восстанавливать биполярные образы размером 7×7 пикселей (49 нейронов). База эталонов содержит первые три буквы фамилии: **«Б», «О», «Н»**. 
Программа проводит автоматическое исследование устойчивости памяти при уровне зашумления от 10% до 100%.

## Реализованные алгоритмы
- **Обучение по правилу Хебба:** Формирование симметричной матрицы весовых коэффициентов с нулевой главной диагональю для создания устойчивых аттракторов (впадин энергии).
- **Ассоциативное распознавание:** Восстановление искаженных образов с использованием пороговой функции активации в синхронном и асинхронном (случайный нейрон) режимах.
- **Генератор шума и пакетное тестирование:** Алгоритм случайного инвертирования заданного процента пикселей и автоматический прогон 360 тестов для оценки критического порога памяти сети.

## Технический стек и Архитектура
Проект построен по принципам чистой архитектуры (Clean Architecture), изолирующей математическое ядро от веб-фреймворка:
- **Domain** (`src/domain/models.py`): Структуры данных, модели биполярных образов и эталонные матрицы букв.
- **Service** (`src/services/hopfield.py`): Ядро сети Хопфилда, матричная алгебра, логика обучения и распознавания.
- **Web** (`src/web/`): REST API на **Flask**, адаптивный интерфейс на **Tailwind CSS** и построение графиков через **Chart.js**.

## Запуск проекта

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Запустите сервер: `python main.py`
3. Откройте в браузере: `http://127.0.0.1:5000`
